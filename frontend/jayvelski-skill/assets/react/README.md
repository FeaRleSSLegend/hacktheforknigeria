# React assets

Dependencies: `react`, `framer-motion`, `lenis`, `tailwindcss@3`. Copy `../tailwind.config.js`, `../index.css`, `../postcss.config.js` to the project, these components to `src/components/` (adjust import paths; `motion.ts` and the hooks may live in `src/lib` and `src/hooks`). Router links: swap `<a>` for your router's `Link` where needed.
